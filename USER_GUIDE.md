# ViewerTone user guide

ViewerTone helps you explore YouTube audience feedback and decide what to try on a future upload. This guide describes the prototype. The example workspace uses synthetic TPD TV data.

## Start with Overview

Overview shows recommendations, comment totals, sentiment, top discussion themes and recent uploads. Select a recommendation to see why it was suggested. Select a video to see its sentiment and the topics that came up in its comments.

## Choose a period

Use **Group by** to choose the scope and **Date range** to select 7, 30 or 90 days.

| Option | What it shows |
| --- | --- |
| Upload date | Videos published in the selected period and their collected comments |
| Comment date | Comments posted in the period across the tracked uploads |
| Compare periods | Comment activity with topic counts compared with the previous period |

The example uses a fixed August 2026 snapshot. If an upload-date range contains fewer than three videos, use **Use latest 3 uploads** to widen the view.

## Explore the comments

- **Content Analysis** lists the videos in scope. Open a video to see its evidence.
- **Audience Insights** lets you filter by topic, video or feedback type. A comment can cover more than one topic.
- **Opportunities** lists suggested actions. Open an action to read its supporting comments.
- **Data coverage** shows the number of collected and analysed comments and how many are awaiting classification. Sentiment uses the analysed comments as its denominator.

## Read the weekly report

Choose **View example report** from Overview or Reports. The fixed report opens with a takeaway and recommended actions, then shows the sentiment breakdown, themes and scope. The report has its own period.

## Example TPD TV weekly report

**11–18 August 2026 · Synthetic example**

Camping and logistics was the most discussed theme. The first action is to make a standalone campsite setup guide. Add a packing checklist viewers can refer to afterwards.

| What to try | Example supporting comment |
| --- | --- |
| Film a standalone campsite setup guide. | “A full campsite setup video would be brilliant. What did you actually use all weekend?” |
| Add a cost breakdown to the next festival vlog. | “How much did the whole weekend cost including food and travel?” |
| Add chapters for key sections of longer uploads. | “Could you add chapter markers for the campsite, food and sets?” |

The example analyses **2,670 comments across 10 simulated uploads**. **71% were positive**, and **903 comments** were tagged camping and logistics. This illustrates the report format using simulated evidence.

## Manage your account

If you have access to the prototype, open **Account** to sign in or create an account. Follow the confirmation link sent to your email address. Enter your YouTube handle with or without the `@` and choose **Save channel**. ViewerTone saves it to your account and continues to show the example data while live analysis is pending.

Use **Forgot password?** on the sign-in screen to request a reset link. Use **Sign out** when you finish on a shared device.

## Privacy settings

Where browser diagnostics are configured, use **Privacy settings → Share browser error reports**. Reporting is off by default. Turning it on allows ViewerTone to send scrubbed error types and app code locations. You can change this preference at any time.
